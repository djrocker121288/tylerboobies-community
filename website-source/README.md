# TYLER BOOBIES WEBSITE V4
Source code for the live HTML/CSS/JavaScript website at https://tylerboobies.com.
The website is served by a Cloudflare Worker.
The images and videos are hosted at assets.tylerboobies.com via a Cloudflare Tunnel.
Copy index.html onto any HTTPS-enabled static host and keep the media URLs or
replace them with copies of authorized assets you have the rights to distribute.
Code is MIT-licensed. Media files, source pictures, voice, music and the
identifiable person are NOT automatically MIT-licensed.
Browser game uses the provided portrait URL as its player texture.
Community share button invokes the device share sheet or clipboard; no backend
submission storage exists yet.
