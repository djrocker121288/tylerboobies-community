# Contributing to the Tyler Boobies community

Use **Issues** to share playable demos, funny game concepts, original character ideas, model issues or Blender/Godot/Unity tutorials. Submit Pull Requests for documentation or other original MIT-licensed code.

Please provide a short description, a screenshot or preview where practical, the engine/tool version, and clear rights and licensing information. Do not submit confidential information, copyrighted work you don't own or a real person's likeness without consent. Mark exports honestly as **experimental**, **unrigged** or **untested** where applicable. Be respectful.

Maintainers may showcase selected contributions on the main site, but publication is not guaranteed.
