# Developer Quickstart — make your own character

Get actual [Tyler models](https://tylerboobies.com/models), the [creator starter pack](https://assets.tylerboobies.com/assets/v4/tyler-starter-pack.zip), and browse games at https://tylerboobies.com.

1. **Choose a format.** GLB/glTF for browsers and Godot, FBX for DCC/engine import workflows, OBJ for meshes, STL for 3D printing.
2. **Inspect in Blender.** Check geometry, textures, scale, axis, armature, animation and mesh cleanup. Some exports are previews, not finished game rigs.
3. **Make your own original character.** Use content you own, model a T-pose, rig and weight-paint, export GLB or FBX, and test in your chosen engine. Check any third-party asset licensing.
4. **Import into a game engine.** Godot supports glTF/GLB scene imports; Unity and Unreal support FBX workflows (and GLB via appropriate plugins/importers). Check skeleton compatibility.
5. **Share a playable demo.** Post a [community issue](https://github.com/djrocker121288/tylerboobies-community/issues/new/choose) with the link, engine, screenshot and license.
